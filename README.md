# El Ñero — GitHub Pages

## Archivos
- `index.html`: página web adaptable a celular y computador.
- `assets/el-nero-diseno.png`: diseño visual usado en la página.
- `EL_NERO_DNS.mobileconfig`: coloca aquí tu archivo de configuración real para que funcione el botón de descarga.

## Publicar
1. Sube el contenido de esta carpeta a la raíz de un repositorio público de GitHub.
2. En Settings → Pages, elige Deploy from a branch, rama `main`, carpeta `/ (root)`, y pulsa Save.
3. Espera a que GitHub Pages publique el sitio.

No subas perfiles que contengan contraseñas, certificados privados o claves secretas. Revisa el contenido del perfil antes de publicarlo.
